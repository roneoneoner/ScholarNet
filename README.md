 ScholarNet 學術大數據分析與合作網絡系統 — 功能全覽

  本專案是一個基於 FastAPI + MS SQL Server 的高效能學術分析平台，旨在透過 Scopus 大數據進行深度的學術影響力與合作網絡分析。

  核心功能模組

  1. 作者基礎資訊與 H-index 追蹤 (Author Info)
   * 複合條件搜尋：支援透過作者 ID、姓名 (姓/名)、所屬機構、城市及國家進行交叉篩選。
   * H-index 監測：即時呈現作者的 H-index、論文總數與被引用次數。
   * 學術歷程分析：追蹤作者在不同時期的機構變遷與國籍分佈。

  2. 多維度合作分析中心 (Cooperation Dashboard)
   * 國家/機構/作者 合作排名：
       * 國家對國家：分析台灣與全球各國的學術連結強度。
       * 機構對機構：追蹤特定大學（如：台大、清大）與國際名校的合作頻率。
       * 個人合作者：列出與目標學者合作最頻繁的全球研究者。
   * 深度鑽取 (Drill-down)：點擊表格中的「合作論文數」，可彈出 Modal 視窗直接檢視具體的 Scopus 論文清單與連結。
   * 一鍵資料匯出：所有統計結果均支援 CSV 格式匯出，方便進行後續研究或 Excel 報表製作。

  3. 諾貝爾得主 × 台灣學者 專項分析 (Nobel Module)
   * 頂尖連結追蹤：專門收錄台灣學者與歷屆諾貝爾獎得主共同發表論文的珍貴數據。
   * 領域分佈視覺化：透過圓餅圖呈現合作論文在物理、化學、生理醫學等學門的比例。
   * 合作路徑探勘：點擊得主姓名即可查看具體的合作年度、主題以及參與其中的台灣研究者。

  4. 學術網絡中心性分析 (Network Analysis - React 版新增)
   * 動態網絡圖譜：使用 React + 視覺化套件呈現作者間的關聯路徑。
   * 中介中心性 (Betweenness Centrality)：計算並識別在學術網絡中扮演「橋樑」角色的關鍵學者。
   * 社群偵測：將關係緊密的學者自動分群（Clusters），分析學術小圈子的形成與互動。

  5. 關聯資料全覽 (Raw Data Matrix - React 版新增)
   * 穿透式查詢：輸入 Scopus ID 後，系統會跨越多張關聯資料表（如基礎屬性、資助計畫、IEEE 標註等），將所有底層屬性對齊並完整呈現。
   * 資料完整性檢查：幫助研究人員確認該學者在各個子系統（如 NSTC 計畫、頂尖期刊）中的紀錄對齊狀況。

  ---

  技術亮點
   * 後端：FastAPI 提供非同步高效能 API，配合 SQL Server 預存程序處理百萬級數據。
   * 前端 (雙版本)：
       * Vanilla JS 版：強調極速載入與零依賴。
       * React + TypeScript 版：提供更豐富的 UI 組件（Radix UI / Tailwind CSS）與複雜的狀態管理。
   * 數據流：整合 Scopus API 與內部資料庫，實現全域學術連結化（一鍵跳轉 Scopus 官網）。

  系統架構圖

   1 graph LR
   2     User((使用者)) --> Frontend[前端介面: React / Vanilla JS]
   3     Frontend --> API[API 層: FastAPI]

   5     DB --> Logic{預存程序 / 複雜 SQL}
   6     API --> External[外部: Scopus Web]
